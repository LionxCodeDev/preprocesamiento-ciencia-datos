# Objetivo
Implementar un flujo de trabajo estructurado para el preprocesamiento de datos, aplicando control de versiones y organización de código para proyectos de Ciencia de Datos.

## Estructura básica de carpetas
- data: Repositorio de archivos
- notebooks: Codigo exploratorio y experimentación
- src: Scripts de Python para limpieza y transformación
- results: Salidas y gráficas.
